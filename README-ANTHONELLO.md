
# Anthonello Michel — Photography Portfolio

Portfolio web de un fotógrafo artístico ficticio,
desarrollado como proyecto académico de 4Geeks Academy.

## Descripción

Landing page de una sola página con una estética
oscura, cinematográfica y minimalista.

## Secciones

- Inicio
- Sobre mí
- Trayectoria fotográfica
- Próximas presentaciones
- Información de contacto

## Tecnologías

- HTML5
- CSS3
- Schema.org mediante JSON-LD

Sin JavaScript ejecutable ni frameworks.

## Características

- Diseño responsive
- HTML semántico
- Navegación mediante anclas
- Accesibilidad y etiquetas ARIA
- Efectos y animaciones CSS
- Metadatos SEO
- Datos estructurados Schema.org

## Validaciones

- HTML: W3C Nu Validator — sin errores.
- CSS: W3C CSS Validator — sin errores.
- Accesibilidad: revisión inicial con WAVE.

## Autoría

Proyecto académico desarrollado para
